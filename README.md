# El Eslabón Perdido

Presentación interactiva en React + Three.js (React Three Fiber) sobre la teoría de la evolución de Darwin y la teoría conspirativa del cruce alienígena.

## Contenido

1. **Expediente** — Portada.
2. **Darwin** — La teoría de la evolución y la selección natural (árbol de la vida animado en 3D).
3. **El Vacío** — Qué es el "eslabón perdido" en el registro fósil.
4. **Razas** — Tarjetas con las razas extraterrestres de la ufología (reptilianos, leoninos, atlantidos, grises, nórdicos, insectoides), cada una con un cristal 3D animado.
5. **La Marcha** — Recreación de "La marcha del progreso" (mono → Homo erectus → Homo sapiens) señalando dónde se ubica el eslabón perdido y la nave que lo sobrevuela.
6. **El Cruce** — La hipótesis del injerto genético alienígena.
7. **Cierre** — Ciencia vs. mito, con fines educativos/de entretenimiento.

## Desarrollo

```bash
npm install
npm run dev
```

## Stack

- React 18 + TypeScript + Vite
- Three.js vía `@react-three/fiber` y `@react-three/drei`
- Framer Motion para las transiciones de UI
- Tailwind CSS
